# 么么英语

> 敲着敲着，就会了 —— 小学英语单词、句子、语法默写练习。

打开网址就能用，**不需要注册、不需要安装、不需要下载**。

---

## 一、怎么打开

### 电脑 / 平板

在浏览器里打开老师发的网址即可开始练习。

iPad 还可以把它变成桌面图标（像 App 一样用）：

1. 用 **Safari** 打开网址
2. 点底部的「分享」按钮
3. 选「添加到主屏幕」
4. 桌面上就会出现「么么英语」图标，以后点开全屏使用

> 注意：微信里打开的网页不能直接「添加到主屏幕」，需要先点右上角「…」，选择「在浏览器中打开」。

### 手机

用浏览器打开网址，点击页面下方的输入框即可弹出键盘开始输入。

---

## 二、怎么用

页面打开后只有三步：

1. **选择题库** —— 上方有两个下拉框，先选大类（小学 / 初中 / 高中 / 拓展），再选具体题库
2. **点击【加载题库】** —— 默认已选好「小学 · 三年级上册」，不想改就直接点这个按钮
3. **开始默写** —— 看页面上的中文意思，用键盘敲出对应英文

四个标签页对应四种练法：

| 标签 | 练什么 |
|---|---|
| 单词默写 | 看中文释义，敲出英文单词 |
| 句子默写 | 看中文句子，敲出完整英文句子 |
| 语法练习 | 选择题，做完会显示解析 |
| 错题复习 | 自动收集做错的题，按记忆曲线提醒复习 |

几个小工具：

- **发音**：点「发音」按钮，或按 `Ctrl` 键播放当前单词读音
- **提示**：显示答案 3 秒（这道题会自动记入错题本）
- **跳过**：跳过当前题目
- **重置进度**：清空本机保存的学习进度和错题（**慎用，不可恢复**）

## 四、学习进度保存在哪里

进度和错题保存在**你自己这台设备的浏览器里**（localStorage），不会上传到任何服务器。

需要注意：

- **换设备或换浏览器，进度不会跟着走**
- **清理浏览器缓存会导致进度丢失**
- 目前还没有账号体系，跨设备同步功能在规划中

## 五、设备建议与常见问题

**推荐**：电脑（物理键盘打字最顺手）或 iPad + 键盘。

**平板/手机上拼音输入法正在输入状态时，请先切到英文输入**再敲字母。

**点「发音」没声音？**

- 确认设备没有静音
- 部分浏览器需要先点一下页面任意位置才能播放声音
- 如果浏览器不支持语音合成，会弹出提示

**打不开或页面显示不正常？** 建议换用 Chrome、Edge 或 Safari 浏览器。

## 七、项目说明（给开发者）

纯静态网页，无框架、无构建步骤、无后端。

```
index.html                    页面入口
style.css                     样式
script.js                     全部逻辑（题库加载、默写判定、错题调度）
manifest.json                 PWA 配置（添加到主屏幕）
icons/                        应用图标（192 / 512 / apple-touch-icon）
fonts/                        本地自托管字体（Nunito 拉丁字符）
question_bank/
  ├─ index_list.json          题库索引（大类 → 题库，含 available 标记）
  ├─ primary_3a.json ~ 6b.json 小学各学期题库
  ├─ junior.json / senior.json 初中 / 高中示例题库
  └─ embedded_banks.js        同上的内置副本，供 file:// 直接打开时使用
```

**本地预览**：在项目目录执行 `python -m http.server 8899`，然后访问 `http://localhost:8899`。

**新增题库**：在 `question_bank/` 下新建 JSON（字段 `words` / `sentences` / `grammar`），把 `index_list.json` 里对应条目的 `available` 改为 `true`，并把同一份数据同步到 `embedded_banks.js`。

**部署**：Gitee Pages（部署分支 `master`）。免费版无自动构建，每次推送后需在仓库的「服务 → Gitee Pages」里手动点一次「更新部署」。
